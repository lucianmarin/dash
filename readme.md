# Dash 1.0

Dash is a new kind of life-stream who lets others see your latest online activities in a clear and simple interface.

### Installation

Create *./dash/* directory on your server and copy all the files there. Make sure there will be *./dash/cache/* sub-directory with CHMOD 777.

You can edit the RSS feed links from inside of *index.php*. Also, you can ping me back on Twitter: @lucianmarin and tell me the link of your Dash so we can build a network out of it.
